# NovelAI: инвентаризация запросов (1.739)

Расширение отправляет компактные параметры в `/api/novelai/generate-image`.
Сервер SillyTavern строит запрос `{ action, input, model, parameters }` к
`https://image.novelai.net/ai/generate-image`. Изменения нужны на обеих сторонах:
прежний сервер всегда добавлял `params_version: 3`, SMEA, Variety+ и другие поля.

| Параметр / функция | V5 Full High / Curated | V5 Full Medium | V4.5 | V4 / V3 |
| --- | --- | --- | --- | --- |
| `params_version` | 4 | 4 | 3 | 3 |
| Шаги | Пользовательские; Anlas Guard ограничивает до 28 | Фиксированно 14 | Пользовательские | Пользовательские |
| Сэмплер | Пользовательский | `k_euler_ancestral` | Пользовательский | Пользовательский |
| `noise_schedule` | Пользовательский, default `native` | Пользовательский, default `native` | Пользовательский, default `native` | Пользовательский, default `native` |
| `scale` | Пользовательский | Пользовательский | Пользовательский | Пользовательский |
| `cfg_rescale` | Пользовательский, 0–1 | 0 | Пользовательский, 0–1 | Пользовательский, 0–1 |
| `negative_prompt` | Пользовательский | Поле отсутствует | Пользовательский | Пользовательский |
| `v4_negative_prompt` | Пользовательский | Пустая caption; без пользовательского UC | Пользовательский | V4: пользовательский; V3: поле отсутствует |
| `v4_prompt` | Есть | Есть | Есть | V4: есть; V3: поле отсутствует |
| Decrisper / Variety+ | Поля отсутствуют | Поля отсутствуют | Прежнее поведение | Прежнее поведение |
| SMEA / SMEA Dynamic | Поля отсутствуют | Поля отсутствуют | Выключены | V4: выключены; V3: доступны, кроме DDIM |
| Precise Reference | Поля отсутствуют | Поля отсутствуют | Доступен при включённой опции | Поля отсутствуют |

Всем моделям передаются промпт, разрешение, seed и `n_samples: 1`.
По умолчанию для всех моделей: `k_euler_ancestral` и `native`.
Принудительный Karras из версии 1.738 убран по выбору пользователя.
Anlas Guard сохранён: до 1 048 576 пикселей и до 28 шагов;
для Medium по-прежнему 14 шагов. Он ограничивает параметры запроса,
а доступность бесплатных генераций зависит от тарифа и лимитов NovelAI.
Доступные настройки сохраняются в профиле подключения, включая `novelaiCfgRescale`.
Ограничения применяются к каждому запросу, в том числе при маршрутизации ExtBlocks
и переопределении модели гардероба. Переключение на Medium не стирает сохранённые
шаги, сэмплер, негатив или настройки референсов остальных моделей.

Для V5 блокируются и картинки-референсы, и связанные текстовые инжекты аватаров,
лорбуков, NPC и гардероба. Общие стили/префиксы/суффиксы и NovelAI tag presets
продолжают работать.

Сборка параметров — чистый модуль `src/providers/novelaiParams.js`. Его копия
`src/endpoints/novelai-image-params.js` используется сервером SillyTavern.
Если переносить расширение на другую установку, потребуется перенести и серверную
правку из `server-patch/novelai.js` с её модулем. После установки серверных файлов
нужно перезапустить SillyTavern.

## Подтверждение и ограничения проверки

Официально подтверждены ограничения Medium: 14 шагов, Euler Ancestral, запрет
пользовательского Undesired Content и CFG Rescale; scale остаётся доступным.
Precise Reference документирован только для V4.5.

Полный официальный JSON Medium публично не документирован. В этой реализации
используется совместимая структура V5: `params_version: 4`, выбранный scheduler,
`cfg_rescale: 0`, пустой `v4_negative_prompt` с `legacy_uc: false`.
Это не перехваченный запрос сайта. Не добавляем предполагаемую строку Heavy UC:
её точное содержание/место применения не подтверждено.

Img2img, inpainting, прозрачность, streaming и UI отдельных character prompts
не добавляются этим обновлением. Произвольные поля клиента не пробрасываются.
Проверки перехватывают исходящий запрос локально; платные генерации не запускаются.
